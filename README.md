# azim-dev.uz

Сайт-портфолио на трёх языках (русский, узбекский, английский) с собственной
админкой: работы, вкладки и тэги добавляются через веб-интерфейс, каждый
объект хранит три перевода.

Было: PHP + MySQL на платном хостинге, админка только на русском.
Стало: Node на serverless-функциях, Postgres, бесплатный хостинг.

```
/            русская версия
/uz/         узбекская
/en/         английская
/admin/      админка
/api/…       API
```

---

## Как устроено

Страница собирается на каждый запрос: тексты интерфейса берутся из
`content/<язык>.json`, блок «Мои работы» — из базы. Готовый HTML на минуту
кладётся в кеш CDN, дальше сутки отдаётся «устаревшая» копия, пока в фоне
готовится свежая. Практический итог: правка в админке появляется на сайте
в течение минуты, а база получает примерно один запрос в минуту независимо
от посещаемости.

```
api/
  page.js              публичная страница (все три языка)
  auth/                вход, выход, текущая сессия
  cases/               работы: список, создание, правка, порядок
  categories/  tags/   справочники
  media/               загрузка и отдача картинок
  _lib/
    db.js              пул подключений к Postgres
    auth.js            scrypt-хэши паролей, подписанная кука сессии
    http.js            маршрутизация по методу, валидация, ошибки
    cases.js           чтение и запись карточек вместе со связями
    taxonomy.js        общая логика вкладок и тэгов
    content.js         данные для страницы
    render.js          сборка HTML

public/                всё, что отдаётся как есть
  assets/              стили, скрипты, шрифты, видео сайта
  uploads/img/         обложки работ, перенесённые со старого сайта
  admin/               интерфейс админки (html + css + js, без сборки)

content/               тексты интерфейса — правятся в коде
db/                    схема и скрипты: миграция, перенос данных, пользователь
scripts/               локальный сервер и проверка перед публикацией
```

Почему тексты интерфейса не в админке: они меняются раз в год и связаны
с вёрсткой (переносы строк, выделенные слова). Через админку правится то,
что меняется регулярно, — работы.

## Первый запуск

### 1. База

Завести бесплатный Postgres (Neon, Supabase — любой) и взять строку
подключения. **Важно:** брать вариант с пулером — у Neon это хост с
суффиксом `-pooler`. Прямое подключение быстро упрётся в лимит соединений,
потому что каждый вызов функции открывает своё.

### 2. Переменные окружения

Скопировать `.env.example` в `.env` и заполнить:

```bash
cp .env.example .env
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"   # SESSION_SECRET
```

Те же две переменные — `DATABASE_URL` и `SESSION_SECRET` — нужно добавить
в настройках проекта на Vercel (Settings → Environment Variables).

### 3. Таблицы, данные, пользователь

```bash
npm install
npm run db:migrate          # создаёт таблицы
npm run db:seed             # переносит 11 работ, 7 вкладок и 6 тэгов
npm run db:admin -- azim    # заводит вход в админку, пароль спросит
```

### 4. Проверить локально

```bash
npm run dev     # http://localhost:3000, админка на /admin/
npm run check   # проверка перед публикацией
```

### 5. Опубликовать

Запушить репозиторий на GitHub, в Vercel нажать Import Project. Сборка не
нужна — `vercel.json` уже описывает, что `public/` отдаётся как статика,
а `api/` разворачивается в функции.

## Работа с админкой

Вход — `/admin/`. Страница закрыта от индексации, а API не отвечает без
сессии.

**Добавить работу.** «Добавить работу» → выбрать картинку → заполнить три
языковые вкладки → указать ссылку → отметить вкладки и тэги → «Сохранить».
Новая работа встаёт первой в списке.

Картинка сжимается прямо в браузере: до 1680 px по ширине и в формат webp.
Фотография с телефона на 8 МБ превращается в файл около сотни килобайт,
на сервер уходит уже готовый.

**Порядок.** Стрелки слева от карточки. Порядок в списке — это порядок на
сайте.

**Скрыть, не удаляя.** Кнопка «Скрыть»: работа пропадает с сайта, но
остаётся в админке.

**Переводы.** У каждого текстового поля три вкладки. Кнопка «Скопировать из
русского» переносит русский текст в текущую вкладку — дальше его нужно
перевести. Оранжевая точка на вкладке языка означает, что там что-то не
заполнено; в списке работ такая карточка помечена «нет перевода».

**Вкладки и тэги** — отдельные разделы. Вкладка без карточек на сайте не
показывается. Удалить занятую вкладку можно только подтвердив это второй
раз.

## Где хранятся картинки

Если в проекте Vercel подключить хранилище Blob (Storage → Create → Blob),
появится переменная `BLOB_READ_WRITE_TOKEN`, и новые картинки будут уходить
туда. Пока её нет — картинки складываются в таблицу `media` и отдаются
по адресу `/api/media/12.webp` с вечным кешем.

Второй вариант рабочий: обложка после сжатия весит около сотни килобайт,
десятки таких строк базе незаметны. Так админка работает сразу после
разворачивания. Подключить Blob можно позже — старые ссылки продолжат
работать.

## Безопасность

- Пароль хранится как scrypt-хэш со своей солью. Забытый пароль не
  восстанавливают, а задают заново: `npm run db:admin -- azim`.
- Сессия — кука HttpOnly, подписанная HMAC на `SESSION_SECRET`, живёт
  неделю. Смена секрета разлогинивает всех.
- Все запросы к базе — параметризованные, строки в SQL не склеиваются.
- Всё, что приходит из формы, проверяется на сервере: длина, тип,
  схема ссылки (только http и https), существование вкладок и тэгов.
- Тип загружаемого файла определяется по сигнатуре в первых байтах, а не
  по заголовку запроса.
- Любые тексты экранируются перед вставкой в HTML.

## Что изменилось при переезде со старого хостинга

- Добавлены узбекская и английская версии, переключатель языка в шапке,
  `hreflang`, отдельные `title` и `description` под каждый язык.
- Админка переписана с нуля: три языка в каждой форме, загрузка картинок
  со сжатием в браузере, порядок карточек, скрытие без удаления.
- Обложки пережаты: 9,6 МБ → 2,2 МБ без потери качества.
- Убрано около 16 МБ неиспользуемых файлов шаблона Sepium и остатки чужого
  брендинга в текстах и alt-подписях.
- Телефон в шапке вёл на московский номер — исправлен на узбекский.
- Починены две ошибки в `main.js`: обращение к несуществующему `.toolbar`
  роняло кнопку мобильного меню, а сломанный импорт `sepium.js` давал 404.
- Все пути к файлам сделаны абсолютными — иначе языковые подпапки ломали
  относительные ссылки.
