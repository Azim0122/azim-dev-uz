# azim-dev.uz

Сайт-портфолио на трёх языках: русский, узбекский, английский.

Раньше это был PHP + MySQL с самописной админкой. Теперь — статический
сайт: контент лежит в JSON-файлах рядом с кодом, сборщик превращает их
в готовые HTML-страницы. Ни базы данных, ни PHP, ни платного хостинга.

```
/            русская версия
/uz/         узбекская
/en/         английская
```

## Как запустить

```bash
npm run dev       # собрать и открыть на http://localhost:3000
npm run build     # просто собрать в dist/
npm run verify    # собрать и прогнать проверки
```

Node.js 18 или новее. Внешних зависимостей нет — только стандартная библиотека.

## Как устроен проект

```
content/           ← ЗДЕСЬ ПРАВИТСЯ ВЕСЬ ТЕКСТ И КОНТЕНТ
  site.json          домен, контакты, видео в блоке «Экспертиза»
  ru.json            все тексты русской версии
  uz.json            узбекской
  en.json            английской
  cases.json         карточки работ (у каждой — три перевода)

assets/            стили, скрипты, шрифты, картинки, видео
uploads/img/       обложки работ
build.mjs          сборщик: JSON + шаблоны → dist/
scripts/
  serve.mjs        локальный сервер для просмотра
  verify.mjs       проверки перед деплоем
dist/              результат сборки (в Git не хранится)
```

## Как поменять контент

**Текст на сайте.** Открыть `content/ru.json` (или `uz.json` / `en.json`),
поправить нужную строку, сохранить. Ключи во всех трёх файлах одинаковые,
поэтому правку легко продублировать на другие языки.

**Добавить работу.** В `content/cases.json` скопировать любой блок из
`items` и заполнить:

```json
{
  "id": "novyy-proekt",
  "url": "https://example.com",
  "image": "uploads/img/novyy-proekt.webp",
  "width": 1680,
  "height": 909,
  "categories": ["popular", "all", "landings"],
  "tags": ["uxui", "dev", "seo"],
  "title":       { "ru": "Название", "uz": "Nomi",   "en": "Title" },
  "description": { "ru": "Описание", "uz": "Tavsif", "en": "Description" }
}
```

Картинку положить в `uploads/img/`. Ширину и высоту указать реальные —
браузер по ним резервирует место и страница не «прыгает» при загрузке.

Допустимые `categories`: `popular`, `all`, `shops`, `landings`, `services`,
`tilda`, `wordpress`. Названия вкладок — в `cases.<язык>.categories`.

Допустимые `tags`: `logo`, `uxui`, `dev`, `seo`, `content`, `semantics`.
Их подписи — в `cases.<язык>.tags`.

**Контакты, почта, телефон.** Только в `content/site.json` — на всех трёх
языках подставятся сами.

**Добавить язык.** Скопировать `content/ru.json` в `content/<код>.json`,
перевести значения, добавить код в `languages` в `site.json`, дописать
переводы названий и описаний в `cases.json`. Больше ничего менять не надо.

После любой правки — `npm run verify`. Проверка ловит недостающие
картинки, пустые переводы, битые SEO-теги и забытую кириллицу в узбекской
и английской версиях.

## Деплой

Сайт живёт на Vercel и пересобирается сам при каждом `git push`
в ветку `main`. Настройки — в `vercel.json` (команда сборки, редиректы
со старых адресов `index.php` и `/admin`, кеширование, заголовки).

## Что изменилось при переезде с хостинга

- Блок «Мои работы» рисуется из `content/cases.json`, а не из MySQL.
  Админка `/admin` больше не нужна и в проект не перенесена.
- Добавлены узбекская и английская версии, переключатель языка в шапке,
  `hreflang`, отдельные `title`/`description` и `sitemap.xml`.
- Обложки работ пережаты: 9,6 МБ → 2,2 МБ без потери качества.
- Убраны неиспользуемые файлы шаблона Sepium (около 16 МБ) и остатки
  чужого брендинга в тексте и alt-подписях.
- Телефон в шапке вёл на московский номер — исправлен на узбекский.
- Починены две ошибки в `main.js`: обращение к несуществующему `.toolbar`
  роняло кнопку мобильного меню, а сломанный импорт `sepium.js` давал 404.
- Все пути к файлам сделаны абсолютными — иначе языковые подпапки
  ломали относительные ссылки.
